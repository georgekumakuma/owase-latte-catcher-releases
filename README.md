# っ🍵Ω負わせラテきゃっちゃ～ 配布ページ

YouTube ライブ配信の、アーカイブに残らないチャット（配信開始前・終了後）を保存するアプリです。

## はじめて使う方

1. 右側の **Releases** から最新版を開き、`LatteCatcher-<バージョン>-full.zip` をダウンロード
2. 好きな場所に展開（例: `ドキュメント\LatteCatcher`）
3. `LatteCatcher\LatteCatcher.exe` を起動

> 初回起動時に Windows の「PC を保護しました」が表示された場合は、
> 「詳細情報」→「実行」を選んでください（署名なしのアプリのため表示されます）。

## 更新について

アプリが自動で新しいバージョンを確認し、画面右下とタスクトレイで通知します。
撮影していない時に自動でダウンロードされ、「再起動して適用」を押すと更新されます。
**撮影中は更新されません。**

新しいバージョンが起動できなかった場合は、自動で元のバージョンに戻ります。

## 以前のバージョン（v2.4 以前）から移行する方

- 旧版のフォルダに full.zip の中身を上書き展開するか、別のフォルダに展開してください
- 設定（`user_settings.json`）は初回起動時に自動で引き継がれます
  （別フォルダに展開した場合は、旧フォルダの `user_settings.json` を
  `%APPDATA%\LatteCatcher\` にコピーしてください）

## このリポジトリのファイル

| ファイル | 内容 |
|---|---|
| `remote_config.json` | アプリが起動時に読み込む設定（YouTube 側の小さな変更への対応用） |
| Releases の `*-full.zip` | 初回インストール用 |
| Releases の `LatteCatcher-app-*.zip` | 自動更新用（手動でダウンロードする必要はありません） |
